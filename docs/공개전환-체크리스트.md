## 1. 라이선스 (가장 중요 — GPL 상속)
- **핵심:** 결과물이 **DCP-o-matic 파생물(GPL-2.0-or-later)** 이 되면, **배포 시 전체를 GPL-2.0-or-later로 소스 공개**해야 한다. 사유화 불가.
- [ ] 공개 시 **`LICENSE` 파일 = GPL-2.0-or-later** 추가(현재 미추가 — 파생 코드 편입 시점에 확정)
- [ ] DCP-o-matic 원저작권(Carl Hetherington) **고지 보존 + 변경사항 표시**(GPL 요구)
- [ ] `NOTICE`/`README`에 "DCP-o-matic 기반 파생/컴패니언" 명시, 원 프로젝트 링크
- [ ] 우리 자체 문서(docs/)의 라이선스 방침 결정(코드와 동일 GPL로 통일 권장)
- [ ] ⚠️ 순수 iOS 측정앱을 **별도 배포(App Store)** 한다면 GPL과의 관계 검토(App Store 배포와 GPL 충돌 이슈 — 별 레포/별 라이선스 분리 고려)
- > 법률 자문 아님. 배포 형태 확정 시 GPL 준수사항 재확인 필요.
