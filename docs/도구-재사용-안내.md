# 빌드한 DCP-o-matic 도구 재사용 안내 (같은 맥의 다른 프로젝트)

> 우리가 소스빌드한 DCP-o-matic 도구(룸 EQ 포함 Player 등)를 **이 맥의 다른 프로젝트에서 가져다 쓰는** 방법.
> 시나리오: **같은 맥에서 참조** (재빌드·패키징 불필요).
> 다른 머신/배포용이라면 이 방식이 아니라 [DCP-o-matic-빌드-실전기록.md](DCP-o-matic-빌드-실전기록.md)(재빌드) 또는 자립 번들 패키징이 필요하다.

---

## 30초 요약
1. 도구는 여기 있다 → **`~/src/dcpomatic/build/src/tools/`**
2. **제자리에서 절대경로로 호출**하면 끝. env 소싱·설치 불필요(dylib가 절대경로로 링크됨).
3. 편하게 쓰려면: `source /Users/homedcp/Claude/Projects/roomtunning/scripts/roomtune-tools.env.sh` → `roomtune-player "/DCP경로"`

---

## 1. 빌드된 도구 목록 (`$ROOMTUNE_TOOLS`)
| 도구 | 용도 |
|------|------|
| **`dcpomatic2_player`** | **DCP 재생 (★ 우리 룸 EQ 포함 — View 메뉴 "Room EQ")** |
| `dcpomatic2` | 메인 GUI (DCP 생성/인코딩) |
| `dcpomatic2_cli` | CLI 인코딩 |
| `dcpomatic2_create` | 필름/DCP 생성 CLI |
| `dcpomatic2_verifier` | DCP 검증 |
| `dcpomatic2_kdm` / `_kdm_cli` | KDM 생성 |
| `dcpomatic2_batch` | 배치 변환 |
| `dcpomatic2_combiner` / `_map` / `_editor` / `_playlist` | DCP 조합/매핑/편집/재생목록 |
| `dcpomatic2_server` / `_server_cli` | 분산 인코딩 서버 |

## 2. 호출 방법 (같은 맥)
```bash
# (권장) 편의 환경 소싱
source /Users/homedcp/Claude/Projects/roomtunning/scripts/roomtune-tools.env.sh

roomtune-player "/Users/homedcp/Desktop/어떤DCP폴더"   # GUI, 룸 EQ 포함
roomtune-cli --help
"$ROOMTUNE_TOOLS/dcpomatic2_verifier" "/DCP경로"

# 또는 절대경로 직접 호출 (소싱 없이도 동작)
~/src/dcpomatic/build/src/tools/dcpomatic2_player "/DCP경로"
```
- 다른 프로젝트의 스크립트/Makefile에서는 `ROOMTUNE_TOOLS=$HOME/src/dcpomatic/build/src/tools` 로 두고 `"$ROOMTUNE_TOOLS/도구명"` 형태로 호출하면 된다.

## 3. 반드시 지킬 규칙 ⚠️
이 바이너리들은 **개발 빌드**라 경로에 묶여 있다:
- ✅ **제자리에서 실행** — `~/src/dcpomatic/build/src/tools/` 안의 바이너리를 그대로 호출.
- ❌ **바이너리만 딴 곳으로 복사 금지** — dylib(절대경로)·리소스를 못 찾아 죽는다.
- ❌ **빌드 디렉토리 이동/`./waf distclean` 금지** — 산출물·리소스가 사라진다.
- 리소스는 `~/src/dcpomatic/build/src/Resources/`에 있어야 한다(스플래시·폰트·libdcp 데이터). 실행파일 기준 `../Resources`로 자동 탐색되므로, **cwd는 아무 데나** 상관없다.

## 4. 런타임 주의점
- **env 소싱 불필요:** dylib가 절대경로(`/opt/homebrew/...`, `~/dcpomatic-env/lib`, `~/src/*/build`)로 링크돼 있어 그냥 실행된다. 단 그 경로들이 그대로 있어야 한다(brew 패키지 삭제/이동 금지).
- **설정(config) 공유 주의:** 설정은 `~/Library/Preferences/com.dcpomatic/`에 있고 **공식 설치앱과 공유**된다. ⚠️ 알려진 이슈: 저장된 **DKDM**이 있으면 우리 빌드가 config 저장 시 크래시(libxml++ 4.4.1 궁합). → 우리 빌드는 **깨끗한 config**로 쓰거나 DKDM을 저장하지 말 것. (별도 수정 예정)
- 일부 CLI는 실행 위치(cwd)에 따라 무해한 `fatal: ...`(git) 경고를 낼 수 있으나 기능엔 지장 없다.

## 5. 다른 머신에서도 쓰고 싶어지면
"같은 맥 참조"는 이 맥 한정이다. 다른 컴퓨터로 가져가려면:
- **재빌드(권장·이식성):** [DCP-o-matic-빌드-실전기록.md](DCP-o-matic-빌드-실전기록.md) + [scripts/roomtune-env.sh](../scripts/roomtune-env.sh)
- **자립 번들:** `dylibbundler`/`install_name_tool`로 의존 dylib를 @rpath로 재작성 + 리소스 동봉해 `.app`/폴더로 패키징(추가 작업 필요 — 요청 시 진행).
