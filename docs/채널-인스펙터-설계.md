# DCP 검수용 오디오 채널 인스펙터 — 코드 레벨 구현 설계서

> **베이스:** DCP-o-matic Player v2.18.44 / 소스 `~/src/dcpomatic` (EQ 룸튜닝 포크, 베이스 커밋 `613ea21`).
> **상태:** 리서치(웹+코드 8에이전트, ~50만 토큰) + Plan 에이전트 소스검증 상세설계 **완료**. **구현 착수 전.** (이전 세션이 `ExitPlanMode` 직후 API 연결 끊김으로 중단되어, 대화 복원으로 이 설계를 문서화함.)
> **관계:** ①측정필터 ②EQ패치백업 ③DKDM크래시(모두 커밋 `613ea21` 완료) 이후 추가로 착수한 **신규 기능**. 사용자 별도 프로젝트인 ④GPU J2K 인코딩과는 무관.

---

## 목적

DCP 재생 검수 시 **채널 매핑을 실측 검증**하는 도구. DCP 실제 채널수에 맞춘 개별 **solo/mute + 채널별 피크 미터**(매핑 오류는 전부 채널 단위 실패이므로 채널 단위 진단이 본체), 그리고 채널별 **진단 EQ 프리셋** + 전체 **X-curve/Flat**(하이브리드).

핵심 통찰: **한 채널만 solo하면 믹스 후 버퍼엔 그 채널만 남으므로, "전체 EQ + 자동 solo" = "채널별 진단 EQ"** — 복잡한 pre-mix 채널별 처리 없이 채널별 진단을 구현.

## 0. 소스 검증 결과 요약 (load-bearing facts)

| # | 검증 대상 | 결론 | 근거 (파일:라인) |
|---|-----------|------|------------------|
| 1 | `remap()` 힙 할당 여부 | **할당한다**(`make_shared<AudioBuffers>`). **단 콜백이 아니라 프로듀서 스레드(`Butler::audio`)에서 호출.** 콜백의 `get_audio`는 링버퍼→`out` **순수 복사**. → **콜백엔 자체 무할당 다운믹스 루프 필요**, remap 재사용 불가. | `util.cc:820-842`(823 alloc), `butler.cc:373`(put시 remap), `butler.cc:392`(get=복사), `audio_ring_buffers.cc:65-107` |
| 2 | identity 매핑 + N=film채널 Butler 가부 | **가능·부작용 없음.** Player가 이미 `film->audio_channels()` 폭으로 방출(remap+audio_processor 모두 이 폭). audio_processor·LFE·게인/페이드는 **모두 Butler 상류(Player)**에서 끝나므로 Butler 매핑 변경과 무관. | `player.cc:1235,1239-1241`, `audio_ring_buffers.cc:51`, `config.cc:1518-1544` |
| 3 | out_p 크기/스트라이드 | RtAudio out_p = **device_channels × frames** 인터리브(FLOAT32). DCP 중간버퍼(≤16ch)는 device보다 넓을 수 있어 out_p에 못 담음 → **별도 사전할당 중간버퍼** 필요. frames ≤ `_audio_block_size`. | `film_viewer.cc:632-637,730` |
| 4 | lock-free 매트릭스 발행 | **더블버퍼 + `std::atomic<int>` 인덱스(SPSC)**. 16×16 float(1KB/buf). GUI가 비활성 버퍼 기록 후 인덱스 release-store, 콜백은 acquire-load. | 신규 |
| 5 | 채널수/라벨 소스 | 개수=`_film->audio_channels()`(DCP 채널수). 라벨=`short_audio_channel_name(i)`. **HI(6)/VI(7) 포함**(스킵 로직 미사용, 0..N-1 전부 노출). mapped 여부=`_film->mapped_audio_channels()`로 회색처리. | `util.cc:603-629`, `film.cc:825,2032-2036` |
| 6 | solo→모니터쌍 | v1 = 소스→device 0/1(L/R) 모노합(×0.707). solo-in-place는 phase2. | 확정 |
| 7 | Butler 재구성 최소화 | Butler는 **identity로 1회 구성**(create_butler 변경) 후 device/DCP 변경 시에만 재생성. solo/mute/preset/EQ는 전부 atomic 실시간 제어. | `film_viewer.cc:232-262` |
| 9 | RoomEQ 통합 | 검수 EQ는 **별도 인스턴스(InspectorEQ)**, biquad 코어만 공유. RoomEQ(룸튜닝, 파일로더)는 그대로 두되 인스펙터 활성 시 자동 바이패스 권고. | `room_eq.h:39-79` |

## 1. 확정 아키텍처 (Strategy 2)

```
Player(film ch, 상류에서 processor/LFE/gain 완료)
      │  _player.Audio  (film->audio_channels() 폭)
      ▼
Butler[ identity map (16→N), _audio_channels = N=film ch ]   ← 변경점(단발)
      │  Butler::audio: remap(identity) → 프로듀서 스레드 (할당 OK)
      ▼  링버퍼 (DCP 레이아웃 N ch)
──────────────  RtAudio 콜백 스레드 (무할당)  ──────────────
 (a) get_audio(mid, frames)          → mid = DCP N ch 인터리브 (사전할당)
 (b) per-source 피크미터  _peak[c]   (mute/matrix 이전, atomic store)
 (c) 무할당 다운믹스  mid[N] → out[dev]   using M[src][out]  (더블버퍼 스냅샷)
 (d) InspectorEQ.process(out, frames, dev)   (post, HI/VI 스킵 없음)
      ▼
 out_p (device dev ch) → 스피커
```

- **결정 A:** Butler를 항상 identity로 구성(단일 코드경로). "normal" 모니터 매트릭스 = `Config::audio_mapping(dev)` 복사 → 인스펙터가 꺼져 있어도 현행과 **수치적으로 동일**한 출력. CPU 추가비용 무시 가능.
- **결정 B:** solo/mute/preset/EQ는 콜백 재구성 없이 atomic 발행으로 실시간 반영.
- **대안(레거시 정확도 보존):** 인스펙터 최초 활성 시에만 Butler를 identity로 재생성. A가 단순하므로 A 권장.

## 2. 변경 파일별 상세

### 2.1 `src/wx/film_viewer.h`
멤버 추가(기존 `RoomEQ _room_eq;`(:208) 근처): `#include "channel_inspector.h"`, `ChannelInspector _inspector;`, `int _inspect_dcp_channels = 0;`.
공개 포워더(기존 `set_room_eq_enabled`(:131) 근처): `inspector_dcp_channels()`, `inspector_channel_labels()`, `inspector_channel_mapped(int)`, `inspector_set_solo/mute(int,bool)`, `inspector_clear()`, `inspector_apply_preset(Preset)`, `inspector_set_global_eq(GlobalEq)`, `inspector_peak_dbfs(int)`, `inspector_has_solo()`. private: `inspector_recompute_matrix()`.

### 2.2 `src/wx/film_viewer.cc`
**(A) `create_butler()`(:232-262)** — `_inspect_dcp_channels = _film->audio_channels()` 캡처, identity `AudioMapping(MAX_DCP_AUDIO_CHANNELS, N)` 대각 1로 Butler 구성(`Config::audio_mapping` 대체), `_inspector.configure(N, _audio_channels, _audio_block_size)` + `inspector_recompute_matrix()`. **suspend 상태에서 호출**(destroy_butler가 먼저 suspend, :213)되므로 버퍼 재할당이 콜백과 무경합.

**(B) `audio_callback()`(:730-762)** — `_inspect_dcp_channels>0 && _inspector.active_pipeline()`이면: `mid = _inspector.mid_buffer(frames)` → `get_audio(NON_BLOCKING, mid, frames)` → `_inspector.meter(mid,frames)` → `_inspector.downmix(mid,out,frames)` → `_inspector.eq_process(out,frames)`. else 폴백=종전 경로. 이후 `_room_eq.process` (인스펙터 활성 시 바이패스 권고).

**(C) `inspector_recompute_matrix()`** — GUI 스레드. has_solo면 solo&&!mute 채널만 device 0/1에 ×0.707 모노합; 아니면 `Config::audio_mapping(dev)` 복사(mute 행 제외). 후 `_inspector.publish(src)` (더블버퍼+atomic 인덱스 release).

### 2.3 무할당 다운믹스 (`ChannelInspector::downmix`)
`acquire`로 활성 매트릭스 인덱스 로드 → 프레임별 `o[j] = Σ_c in[c]·M.g[c][j]`. noexcept, 힙 할당 0.

### 2.4 lock-free 발행 (SPSC 더블버퍼)
`MatrixSrc _matrix[2]; atomic<int> _pub{0};`. `publish`: 비활성 버퍼(`1-_pub`)에 기록 후 release-store로 플립. 단일 writer(GUI)·단일 reader(콜백) 표준 SPSC. EQ 밴드도 동일 패턴(`_eq_bands[2]`+`_eq_pub`).

### 2.5 기존 RoomEQ / "Room EQ (test)" 메뉴 처리
- **코어 공유:** `room_eq.h`의 `Biquad`/`State`/`peaking·shelf·pass`를 `src/wx/biquad.h`로 추출(권장) → room_eq.h + channel_inspector.h 공용. (미추출 시 ~45줄 복제 허용.)
- **HI/VI 스킵 분리:** RoomEQ의 `c==6||c==7 continue`(room_eq.h:69-71)는 룸튜닝 전용. InspectorEQ는 다운믹스 후 device 채널 작용이라 스킵 없음.
- **바이패스 권고:** 인스펙터 활성 동안 `_room_eq` 자동 바이패스.

### 2.6 `src/tools/dcpomatic_player.cc` — 메뉴/다이얼로그
ID enum(`ID_tools_channel_inspector`, :146 근처) → Tools 메뉴 Append(:742) → Bind(:257) → 핸들러(system_information 패턴 :1082-1088 복제) → `wx_ptr<ChannelInspectorDialog> _channel_inspector_dialog`(:1312) → `#include "wx/channel_inspector_dialog.h"`. `_viewer`는 값 멤버(:1310)라 `FilmViewer&` 전달 가능.

## 5. 진단 EQ 프리셋 계수 (fs=48000, RBJ)

| 프리셋 | 자동 Solo | 밴드 | Type | Fc(Hz) | Q | Gain(dB) |
|--------|-----------|------|------|--------|-----|----------|
| **Dialogue Check** | C(2) | HP/LP/PK | 300 / 3400 / 2000 | 0.707/0.707/1.0 | —/—/+3 |
| **LFE Only** | LFE(3) | LP×2 | 120 / 120 | 0.707 | — (12dB/oct) |
| **Surround Ambience** | Ls(4)+Rs(5) | HP/HS | 80 / 8000 | 0.707 | —/+3 |
| **HF Integrity** | (전체 믹스) | HP | 8000 | 0.707 | — |
| **Flat**(전역) | — | 없음 | — | — | — |
| **X-curve**(전역) | — | HS×2 | 2000 / 10000 | 0.5 | −6 / −6 |

> X-curve는 shelf 2단 근사(정밀도 필요 시 phase2 FIR). Dialogue Check의 HP+LP=밴드패스.

## 6. 구현 단계 (의존 0→1→2→3→4→5)
- **Phase 0 — 코어 추출:** `biquad.h` 분리, room_eq.h가 include. **검증:** 기존 룸EQ 동작 무변화(회귀).
- **Phase 1 — 엔진(비-UI):** `channel_inspector.{h,cc}`. **검증:** §7 헤드리스 하니스로 downmix/EQ/meter 수치 검증.
- **Phase 2 — 파이프라인 배선:** create_butler identity화 + audio_callback 재구성 + 포워더. solo/mute 없으면 **출력이 현행과 동일**해야 함. **검증:** 다채널·스테레오 청감/파형 동일.
- **Phase 3 — 라우팅 제어:** solo/mute/peak atomic + recompute_matrix. **검증:** 실시간 반영, 글리치·크래시 없음.
- **Phase 4 — UI:** dialog + 메뉴/Bind/wx_ptr + peak 타이머. **검증:** GUI 스모크.
- **Phase 5 — 진단 EQ 프리셋:** §5 프리셋 + 전역 Flat/X-curve + 배지 + RoomEQ 자동 바이패스. **검증:** 프리셋별 청취.

> Phase 2까지가 "무행동 동등성", Phase 3+가 기능.

### 리스크
1. 결정 A 상시 다운믹스 → 미사용 시에도 경로 변경(회귀 위험). 완화: Phase 2에서 normal 매트릭스=Config매핑 **비트-동등** 검증. 불안하면 결정 B.
2. 블록사이즈/장치 전환 시 중간버퍼 재할당은 반드시 suspend 상태(:213 보장).
3. DCP 채널수 0 / device 0 폴백 경로 필수.
4. EQ 상태 연속성: 프리셋 전환 시 밴드 수 변경시에만 `_eq_state` 클리어(클릭음 회피).
5. solo 모노합 → Ls+Rs 프리셋 스테레오 상실(v1 한계, 문서화).
6. `Config::audio_mapping(dev)`는 GUI 스레드에서만 호출, 콜백은 스냅샷만 읽음.

## 7. 검증
### 7.1 헤드리스 단위 하니스 (권장 필수, `test/` Boost.Test)
`ChannelInspector`가 wx 비의존 → GUI 없이: downmix 정확성(dev>dcp, dev<dcp), **normal 매트릭스 == 종전 remap 결과**(결정 A 회귀 증명), solo/mute 매트릭스, meter 피크(pre-mute), EQ 주파수응답 FFT(§5 정합 + 클램프), lock-free TSan(레이스 0), 무할당(malloc 후킹).

### 7.2 실기 GUI 스모크 (사용자 실기 필요)
1. 스테레오/헤드폰: 5.1 DCP 재생, 인스펙터 열기 전 출력==종전(동등성). 2. 다채널(≥6ch) 1:1. 3. Solo=C→C만 L/R, Mute=C→C 소거, 피크미터 반영. 4. HI/VI 목록 노출 + 동작. 5. 프리셋 4종 자동solo+커브+배지. 6. 전역 Flat/X-curve. 7. 재생 중 전환 시 크래시·글리치 없음. 8. DCP 언로드→다른 채널수 로드 시 행 재구성.
