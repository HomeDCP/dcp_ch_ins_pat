# 측정 기반 룸튜닝 워크플로 (RoomTune × DCP-o-matic 플레이어)

데모 EQ(하드코딩 1밴드)는 제거됐다. 이제 플레이어의 룸 EQ 는 **실측 결과 파일**에서
필터를 읽는다. 이 문서는 "측정 → 필터 파일 → 재생 적용"의 실전 절차다.

목표 사용처: DCP-o-matic **Player** 의 재생 출력(소프트웨어 극장 B-chain)만 정밀 튜닝.
내보내는 DCP 는 오염되지 않는다.

---

## 0. 준비물
- 계측 마이크: UMIK-1(USB) 권장, 또는 iPhone(임시). 마이크 **캘리브레이션 파일** 필수.
- 측정 SW: [REW (Room EQ Wizard)](https://www.roomeqwizard.com/) — 무료.
- 재생: 이 저장소의 EQ 포크 플레이어(`~/src/dcpomatic/build/src/tools/dcpomatic2_player`).

## 1. 측정 (REW)
1. REW 실행 → Preferences 에서 마이크 캘리브레이션 파일 로드(내장 마이크면 프로파일 역보정).
2. 재생/입력 장치를 **실제 튜닝 대상 경로**(소스기기 → 스피커)로 맞춘다.
3. **측정 중에는 룸 EQ 를 끈다**(순환 보정 방지 — 플레이어의 `View > Room EQ` OFF).
4. 스피커 각각(2.0/2.1) + 청취 위치에서 ESS 스윕 측정. 공간 평균(MMM/여러 지점)이 이상적.

## 2. 타깃 커브 + 필터 생성 (REW)
1. 측정 결과에 **타깃 커브**를 건다. 극장 기준은 **X-curve**(고역 롤오프);
   홈 환경은 완만한 하우스 커브도 가능.
2. REW **EQ** 창 → Equaliser 를 **Generic** 으로 → **Match Response to Target**.
3. 엔진 규칙에 맞춰 다듬는다:
   - **부스트 최소화, 피크 컷 중심**(부스트는 어차피 +6 dB 로 클램프됨).
   - 딥(깊은 골)은 부스트로 메우지 말 것 — 물리적 처리 권고.
   - 시간영역 문제(RT60/SBIR)는 EQ 아닌 흡음/배치로.

## 3. 필터 파일 내보내기 (REW → RoomTune)
REW EQ 창에서 **`Save` → "Filter Settings as text"** (= EQ APO 포맷).
예:
```
Preamp: -4.0 dB
Filter 1: ON PK Fc 42.0 Hz Gain -6.0 dB Q 5.000
Filter 2: ON LS Fc 50.0 Hz Gain  2.0 dB Q 0.700
Filter 3: ON HS Fc 8000 Hz Gain -3.0 dB Q 0.700
```
지원 타입: `PK`, `LS`, `HS`, `LP`, `HP`. `Preamp` 는 헤드룸(감쇠만 반영).
`OFF`/`None` 필터는 무시. (샘플: [`examples/room_eq.example.conf`](../examples/room_eq.example.conf))

## 4. 배치 + 재생 적용
파일을 둘 중 하나로:
```bash
# 방법 A: 기본 경로
mkdir -p ~/.config/roomtune && cp my_room.txt ~/.config/roomtune/room_eq.conf

# 방법 B: 환경변수로 경로 지정 후 플레이어 실행
ROOMTUNE_EQ_FILE=/path/to/my_room.txt ~/src/dcpomatic/build/src/tools/dcpomatic2_player
```
플레이어 실행 시 stderr 에 로드 로그가 뜬다:
```
[RoomEQ] loaded 6 band(s), preamp -4.0 dB from /Users/.../room_eq.conf
```
플레이어에서 **`View > Room EQ (test)`** 체크 → 룸 보정 ON. 끄면 원본과 A/B 비교.

> 파일을 수정하면 플레이어를 **재시작**해야 반영된다(로드는 시작 시 1회).

## 5. 검증
- A/B: 토글 ON/OFF 로 저역 부밍/고역 밝기 차이 확인.
- 정량: REW 로 EQ ON 상태를 **재측정**해 타깃에 수렴하는지 확인(1~2회 반복).

## 설계 노트 / 한계 (v1)
- **fs 48 kHz 고정 가정**(DCP 표준). 96 kHz DCP 는 계수가 어긋나므로 추후 fs 플러밍 필요.
- **전 주채널 동일 필터**(L/R/C/Ls/Rs 공통, HI/VI 제외). 채널별 개별 파일은 v2 확장 여지.
- PK 필터는 RBJ 와 정확히 일치. 셸프는 Q 기반 RBJ(EQ APO 계열과 일치).
- 측정 소스는 우선 **REW 파라메트릭 텍스트**. miniDSP biquad 계수 직입력이나
  자체 iPhone 앱 JSON 스키마는 필요 시 로더에 포맷 추가로 확장.
